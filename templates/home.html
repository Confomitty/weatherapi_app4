Weather Data API

URL Format :
http://127.0.0.1:5001/api/v1/station - To get all time data for one station
http://127.0.0.1:5001/api/v1/yearly/station/year - To get yearly data for one station
http://127.0.0.1:5001/api/v1/station/date - To get data for one station one date

URL Example:
http://127.0.0.1:5001/api/v1/10
http://127.0.0.1:5001/api/v1/yearly/10/1988
http://127.0.0.1:5001/api/v1/10/1988-10-25
